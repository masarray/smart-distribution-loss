# Global language behavior

Smart Distribution Loss supports **English (`EN`)** and **Bahasa Indonesia (`ID`)** in the browser UI.

## Selection order

On first visit the app chooses a language with this lightweight order:

1. explicit `?lang=en` or `?lang=id` query parameter;
2. previously saved browser preference (`localStorage`);
3. Indonesian browser locale (`id` / `id-ID`) or Indonesian timezone (`Asia/Jakarta`, `Asia/Makassar`, `Asia/Jayapura`);
4. English fallback for other visitors.

The flag control in the application header always allows the visitor to switch language manually. The choice is stored locally for later visits.

## Privacy boundary

Language detection does **not** request browser geolocation permission and does **not** call an IP-geolocation service. It uses only browser locale/timezone signals already available locally. No language-location signal is uploaded by the application.

## Engineering terminology

Technical identifiers, asset IDs, electrical units, CSV headers, schema names, Pandapower result contracts, and audit fingerprints remain language-neutral and are not rewritten. Only human-facing UI copy is localized.
